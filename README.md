# Remotion Worldview Course｜费曼式程序化动效课程

这是一套按“**一个对话只完成一轮**”持续建设的课程。仓库会保留30轮总路线，但不会提前用概要冒充完整课程。

每轮课程都需要单独完成：

    世界观解释
    → 核心因果模型
    → 可见代码
    → 代码示例
    → Remotion Studio 运行结果
    → 因果关系讲解
    → 费曼式复述

## 当前进度

当前已完成 **00—01轮**。本次新增 **01｜React / JSX：用组件描述一帧画面**。

运行：

```bash
npm install
npm run dev
```
