# 04｜Determinism：任意一帧都能独立重建

## 费曼类比

确定性像按编号领取照片：无论先要第 90 张还是第 5 张，只要编号和素材相同，拿到的图片都相同。渲染器因此可以跳帧、重试和并行。

## 纯函数要求

    same(frame, fps, props, assets) → same image

`Math.random()`、`Date.now()`、CSS 动画和跨帧累积状态会破坏契约。随机视觉必须使用固定种子；持续运动必须由 frame 直接求值。

## 为什么重要

非确定性问题往往在 Studio 播放时不明显，却会在多线程渲染、重新导出或抽取静帧时出现。它会让错误难以复现，也让审计失去证据。

## 参数实验

同一帧刷新五次并截图比对；先访问 100 帧再回到 20 帧；分别从头播放与直接跳到中间，画面必须一致。

## 本轮结论

> 时间轴不是状态历史，而是可寻址的输入空间。
