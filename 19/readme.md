# 19｜Video：嵌入、裁剪与同步视频

> 阶段：完整作品

## 为什么学习这一轮

这一轮解决 `video` 在程序化视频中的职责、输入、输出和边界，让它能够被参数化、逐帧检查并迁移到其他作品。

## 核心问题

- 它在 `FrameImage = f(frame, fps, props, assets)` 中改变了哪个输入或变换？
- 它应该属于 Composition、Scene、Layer、Asset 还是 Render 边界？
- 哪些参数具有真实语义和单位？
- 起始帧、中间帧、结束前一帧分别应该看到什么？

## 建议实验

1. 创建一个最小可见例子，只暴露本轮主要参数。
2. 写出三个关键帧预测，再在 Studio 中逐帧核对。
3. 故意制造一个边界错误，记录它如何进入最终画面。
4. 将本轮能力接入前一轮作品，但保持代码职责清楚。

## 完成标准

学习者可以用白话解释 `video`，写出语义提示词，指出决定结果的关键代码，并预测一个参数改动产生的视觉后果。

## 本轮结论

> Video：嵌入、裁剪与同步视频 必须成为可解释、可寻址、可复现的时间系统的一部分。
