# Audit｜语义卡片组件

## Prompt audit

- [ ] 对象、时间意图、单位和可编辑参数明确。
- [ ] 描述了起点、终点与边界行为。

## Code audit

- [ ] 画面只由 frame、fps、props 和明确素材推导。
- [ ] 没有 CSS 时间动画、实时钟或跨帧累积。
- [ ] 有意义的数字已命名，插值边界已处理。

## Runtime audit

- [ ] 直接跳到任意帧与顺序播放结果一致。
- [ ] 起始帧、中间帧、结束前一帧符合预测。
- [ ] 修改参数只改变它声称控制的视觉结果。

## Causal reflection

用两句话解释：哪个输入通过哪段代码，造成了哪个可见结果？
