# Audit｜Props Contract：同一规则生成不同卡片

## Structure prediction

先画出预期组件树：

```text
Scene
└── ...
```

## Prompt audit

- [ ] 对象、父子关系和重复关系明确。
- [ ] Props表达内容或可控视觉语义。
- [ ] 时间责任边界明确。

## Code audit

- [ ] 组件名可以直接帮助解释画面树。
- [ ] 没有无意义的包装组件。
- [ ] 重复元素使用数据与稳定key。
- [ ] 内容、结构、样式、时间没有随意混合。

## Runtime audit

- [ ] 修改一个Prop只影响它声称控制的结果。
- [ ] 增加一项数据无需复制组件代码。
- [ ] 同一组件多个实例互不干扰。
- [ ] 直接跳帧时展示状态正确。

## 费曼复述

不用“组件化”“抽象”等词，向非程序员解释：为什么这张画面要拆成这些部分？
